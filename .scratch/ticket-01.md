## What to build

在 WinUI 3 参考截图宿主（`tools/winui-reference`）中建立 2D 流式装箱规划器与单页多控件渲染画布，打通从“输入多个不同控件 → 动态排入 1920×1080 单画布 → 单次 350ms 收敛导出 → 相对坐标切出紧凑单图与独立 JSON”的端到端最小垂直闭环。

通过将多个不同控件紧凑排入单页并共享单次动画收敛等待，消除单控件单窗口频繁刷新的吞吐瓶颈。

## Acceptance criteria

- [ ] 支持在命令行中传入多个指定控件（如 `--control Button,CheckBox` 或多个候选控件），系统将其所有支持状态集中排入同一张 1920×1080 DIP 的瞬态拼版画布
- [ ] 所有槽位控件在可视树中正确完成自适应尺寸测量（DesiredSize + 16 DIP 出血边距），并在画布上保持流式紧凑排布
- [ ] 单页仅经历一次 3 帧渲染与 350ms 动效收敛等待，单次调用 `RenderTargetBitmap` 导出整页 BGRA 像素缓冲
- [ ] 导出后根据每个控件槽位在宿主根容器中的相对视觉几何边界，准确切出紧凑单图并写入 `<Control>_<state>_<theme>.png` 与配套指纹 JSON
- [ ] 裁剪出的单图尺寸与内容包围盒完全符合原规范，槽位间无相互串扰与重叠裁切
