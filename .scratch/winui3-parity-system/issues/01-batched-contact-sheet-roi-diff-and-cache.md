# 01：落地状态拼版截图、有效对比区（ROI）四重门禁与双端用例指纹缓存

**要构建什么：** 升级 WinUI 3 官方参考截图宿主与本框架像素差分器，使参考截图按「单控件 × 单主题 × 单后景」生成状态拼版图集并切出 16 DIP 紧凑出血单图，本框架差分器全局复用单实例离屏渲染器，在联合包围盒外扩 2px 的有效对比区（ROI）内执行四重门禁（内容包围盒、自由维度固有尺寸、ROI 均值/p95、显著色差像素占比），并支持双端用例指纹增量缓存与合成底板参数预留。

**阻塞项：** 无（可立即开始；核心代码已在本轮补丁中落盘，本工单负责在具备 GPU/.NET 环境的机器上完成端到端实机跑通与验证）。

**状态：** ready-for-agent

- [ ] 参考截图宿主在 `--batch` 模式下按「控件 × 主题 × 后景」生成水平网格状态拼版，共享单次 350ms 动画收敛并切出紧凑单图与含 `fingerprint`、`backdrop`、`explicitWidth` 的 JSON 元数据
- [ ] 参考截图宿主二次运行相同参数时命中 `fingerprint` 缓存直接跳过，传入 `--no-cache` 时强制重截，传入 `--save-sheet` 时保留 `_sheet.png` 拼版大图
- [ ] 本框架差分器全程复用单个离屏渲染会话实例，二次运行未修改控件源码时命中源码指纹缓存跳过 GPU 重绘
- [ ] 差分器仅在有效对比区（ROI）内计算 `meanDe`、`p95De` 与 `overLimitRatio`，并在热力图中标出 ROI 边界框，单测验证大面积一致背景不再稀释局部色差且固有高度偏差（如 36px vs 32px）能被门禁准确拦截
- [ ] 展台「Pixel parity」报告页正确加载并展示 ROI 四重门禁指标、后景类型与缓存命中统计
