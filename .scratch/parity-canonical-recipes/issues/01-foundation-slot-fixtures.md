# 01：容器标准插桩通用辅助库与配方契约基础

**要构建什么：** 
在基准控件像素差分器中提供通用的容器与复合控件标准插桩生成器，使得所有依赖子项渲染的容器控件（面包屑、树形、堆叠面板、滚动视口、列表等）能够直接复用统一的 3 级路径、2 级树形与 3 行纯文本规范插桩，并支持递归的禁用态半透明与变灰传播，彻底消除双端手写 mock 数据的漂移与重复代码。

**阻塞项：** 无（可立即开始）

**状态：** closed

- [x] 提取通用的路径与分段插桩辅助函数，固定输出 `Root > Folder > File.txt` 的文本与几何
- [x] 提取通用的树形展开插桩辅助函数，固定输出根节点 `Root`（首项选中态）与子节点 `Child`
- [x] 提取通用的垂直列表/堆叠插桩辅助函数，固定输出统一字号与间距的 `Row 1`、`Row 2`、`Row 3`
- [x] 实现通用的递归禁用态（`disabled`）传播，保证所有子插桩文本和图标同步应用半透明度衰减与变灰
