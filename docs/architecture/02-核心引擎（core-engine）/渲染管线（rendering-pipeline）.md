# 渲染管线

## 1. 核心问题与定位
现代高分屏桌面应用往往包含大量圆角矩形、边框、高模糊阴影、裁剪区域与矢量字形。如果沿用传统 CPU 逐个绘制、频繁切换管线状态的做法，在复杂界面下很快会遇到绘制调用瓶颈。本模块阐述如何以统一的 GPU 驱动架构高效呈现全部界面图元。

## 2. 核心概念模型
- **超级着色器与统一图元描述**：将圆角矩形、边框、渐变、阴影、图像切片与字形抽象为结构紧凑的统一图元实例，在 GPU 端通过分支着色完成绘制，消除频繁的着色器切换。
- **全局索引驱动的多重间接绘制**：所有变换矩阵、裁剪框与扩展载荷存放在全局共享缓冲池中；每个图元仅携带轻量的全局索引，由 GPU 自主完成剔除与合批绘制。
- **双通道深度与解析阴影**：不透明与半透明图元分通道排序；阴影不使用昂贵的多遍高斯模糊贴图，而是基于高斯误差函数在像素着色器中直接解析求值。

## 3. GPU 帧渲染管线

```mermaid
flowchart LR
    Upload["上传差分图元与辅助缓冲"] --> Cull["计算着色器：视口与裁剪剔除"]
    Cull --> Sort["GPU 64 位基数排序（层级 + 深度）"]
    Sort --> MDI["单次或极少次间接绘制提交"]
    MDI --> Shade["统一着色器（SDF 圆角 / 解析阴影 / 纹理采样）"]
    Shade --> Present["合成与屏幕呈现"]
```

## 4. 关键设计取舍
- **解析阴影替代离屏模糊**：虽然离屏高斯模糊能处理任意复杂形状的投影，但会带来大量临时渲染目标切换与显存带宽消耗；针对 UI 中占绝大多数的圆角矩形容器，解析阴影在单遍着色内即可得到平滑柔和的效果且零额外显存分配。
- **无设备地址偏移的全局索引**：所有图元直接引用全局缓冲下标，不在运行时动态计算局部偏移，简化着色器逻辑并避免跨组件合并后的索引错位。

## 5. 边界与不变量
- **全局索引一致性**：跨组件合并图元后，图元持有的变换、裁剪与载荷索引必须指向同一帧全局表中的真实位置。
- **安全退出与资源回收**：窗口销毁或交换链重建前，必须等待 GPU 队列完全空闲后再释放同步信号量与显存资源。
