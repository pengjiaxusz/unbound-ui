# ADR-0025：按钮原生矢量图标、自适应表单标签列与阅读限宽容器

- **状态**：已采纳
- **影响 crate**：`unbound-widgets`、`unbound-app`、`unbound-theme`

## 背景

复杂桌面应用在组合表单、工具栏与设置页时暴露出三类框架层排版缺口：

1. **按钮缺少轻量矢量图标槽**：`ButtonDesc` 仅支持纹理型 `IconDesc`，调用方为了给按钮加播放、刷新、更多等常见图标，容易在按钮文案中直接拼入 Unicode 符号（如 `▶`）。在 Windows 上此类符号会触发彩色 Emoji 字体回退，出现基线偏移、溢出按钮边界与主题色失配。
2. **表单标签列定宽无法适配东亚长标签**：`SchemaForm` 固定标签列宽在 CJK 多字标签叠加继承状态标记时会直接与右侧输入控件碰撞重叠；同时缺少行尾动作槽，迫使调用方在表单下方重复渲染第二遍列表以承载「重置/还原」类行级动作。
3. **宽屏下缺少统一阅读限宽与分组收纳容器**：`SettingsCard` 默认随父容器 100% 拉伸，在宽屏视口下导致左标题与右控件相距数百像素，视觉扫视断裂；且设置与表单页缺少与 `SettingsCard` 同视觉语汇的可折叠分组卡片（`Expander`）及行尾溢出菜单约定。

## 决策

1. **`ButtonDesc` 原生支持 `ShellIcon` 矢量图标槽**：
   - 在 `ButtonDesc` 中新增可选的矢量图标字段（前置或后置），布局与绘制阶段直接复用 `shell` 矢量图标几何与当前按钮前景色令牌，不依赖外部纹理上传，且在悬停/按下/聚焦态下保持图元数量恒定。
2. **`SchemaForm` 自适应标签列与行尾动作槽**：
   - 支持按当前表单字段测量（或显式配置比例/最小最大像素范围）计算标签列宽，超限时按 `elided_text` 规则省略并保留悬停提示，严禁标签与右侧控件重叠。
   - 在每行右侧提供可选的行尾动作槽（如状态徽章 + 重置按钮），使继承态、覆盖态与还原操作在同一行内闭环完成。
3. **阅读限宽容器与 `SettingsCard` / `Expander` 统一骨架**：
   - 在 `unbound-theme` 定义标准表单/设置页最大阅读宽常量（默认 `1000px`），在 `unbound-app` 提供 `readable_column`（或 `SettingsCard` 限宽包装）与同风格 `Expander`（可折叠设置卡片），保证宽屏下表单紧凑易扫视、低频区块可默认折叠。

## 备选方案

- **仅在业务层绕开 `SchemaForm` 并去掉按钮图标**：短期改动小，但所有使用 `unbound-ui` 的桌面应用都会重复踩中 Emoji 回退与宽屏表单拉扯，违背框架提供开箱即用 Win11 / Fluent 观感的定位，故否决。

## 后果

- 既有 `ButtonDesc::label(..)`、`SchemaFormDesc` 与 `SettingsCard` 调用保持源码向后兼容；新能力均通过增量 builder 方法暴露。
- 控件无头测试需同步覆盖：矢量图标按钮在各交互态下图元数守恒、CJK 长标签 `SchemaForm` 零边界重叠、限宽容器在超宽视口下宽度钳制。
