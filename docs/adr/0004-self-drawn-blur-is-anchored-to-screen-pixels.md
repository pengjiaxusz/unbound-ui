# ADR 0004：自绘后景的磨砂强度锚定屏幕物理像素

- 状态：已采纳
- 日期：2026-11-18
- 相关需求：issue #29

## 背景

自绘纹理的磨砂强度并不是一个常数。它先按“壁纸像素 × (纹理上限宽 / 裁切宽)”折算到降采样后的纹理空间，再把纹理贴回主屏。折算下来，真正落在屏幕上的磨砂半径等于「基准强度 × 铺满系数」，而铺满系数是主屏尺寸与壁纸尺寸之比。

后果是观感随素材漂移：同一台机器上换一张分辨率不同的壁纸，磨砂强度就变；4K 壁纸配 1080p 屏时半径只有基准值的一半，壁纸的大尺度轮廓仍然清晰可辨，与系统云母那种“结构被抹掉”的观感明显不同。这正是自绘与原生观感不一致的主要来源之一。

## 决策

- 磨砂强度的语义改为**屏幕物理像素**：目标强度是常数，与壁纸分辨率、屏幕分辨率、显示缩放都无关。
- 生成时按铺满系数反算回纹理空间，保证纹理空间与屏幕空间的观感一致。
- 纹理分辨率上限保持不变：目标是抹掉结构而不是还原细节，明度已被压进窄色带，提高上限只增加模糊、编码与上传成本，不改善观感。

## 备选方案

- **锚定逻辑像素**：与 XAML 侧材质的行为一致，但与系统合成器的固定强度不同源，同一台机器上两套实现仍会分叉。
- **维持壁纸像素语义**：改动最小，但观感随壁纸漂移，无法建立稳定的验收基线。
- **把强度做成用户可调**：把标定问题交给用户，但展台变成调参面板，且系统云母没有对应旋钮，两侧仍无法对齐。

## 后果

- 基准强度需要一次标定：初期用无头数值断言锁住纹理的空间梯度能量，屏幕捕获对照通道到位后再做精确校准。
- 纹理规格中的磨砂强度字段语义变更（从壁纸像素改为屏幕像素），必须与生成请求、失效条件、调用方一起对齐。
- 该强度不再随壁纸变化，意味着同一台机器上换壁纸只会改变色调与构图，不会改变磨砂观感——这正是需要的不变量。
