# ADR 0006：自绘变体覆盖边界与组合回退呈现

- 状态：已采纳
- 日期：2026-11-18
- 相关需求：issue #29

## 背景

材质种类与来源两轴正交之后，会出现 6 档材质 × 3 档来源的组合。其中一部分组合根本无法实现：

- **亚克力**的辨识特征是噪点、饱和度提升与层叠感，而自绘路径只能拿到壁纸、拿不到窗口背后的实时内容。做出来的近似既不像系统亚克力，也无法与原生亚克力对齐，属于负收益。
- **沉浸式后景**是公开文档未收录的取值，只在较新系统版本上存在。为它自创一个自绘变体，等于自造一个系统里并不存在的东西。
- **云母变体**相对标准云母的差异主要落在色调层次上，自绘只需多一组色调参数，几乎没有额外成本。

因此并非每种材质都需要自绘变体，需要显式划定这条边界。

同时，“组合选不了”在界面上有两种性质完全不同的情形，处理方式也必须不同：

- **机器能力不足**（构建号不够、预乘合成不支持）是硬约束，选了也只会回退，用户只会认为是缺陷；
- **组合本身非法**（该材质没有自绘变体）是产品事实，用户亲自选一次并看到回退结果，恰恰是展台存在的意义。

## 决策

- 自绘变体只覆盖**标准云母**与**云母变体**两种材质。
- **亚克力**与**沉浸式后景**只走原生来源。
- 组合不可用时分两类处理：
  - **机器能力不足**：界面禁用该组合并标注原因（例如“需要 Windows 11 22621 及以上”“当前表面不支持预乘合成”）。
  - **组合本身非法**（该材质没有自绘变体）：界面**允许**用户选中，由后景计划回退，并在读出面板明确显示“已回退到 X”与回退原因。
- 材质种类为“无”时，来源轴折叠：不请求任何系统材质，也不生成任何纹理。
- 回退后的实际组合必须由后景计划给出，界面不得自行推导，也不得凭界面状态猜测系统是否支持。

## 备选方案

- **每种材质都做自绘变体**：表面上是“全覆盖”，但亚克力与沉浸式后景的自绘版本注定对不上原生，反而制造一组误导性的对照。
- **一律禁用不可用组合**：语义最严格，但用户无法亲自验证“选了亚克力会发生什么”，展台的对照价值下降。
- **一律允许选中并回退**：灵活，但把机器能力不足暴露成可点的选项，用户会反复点到同一条回退路径。
- **由界面层决定禁用与否**：展台最了解当前构建号与材质列表，但同一套规则会在展台、宿主与未来其它宿主之间复制多份。

## 后果

- 材质种类与来源之间存在有意的稀疏关系，必须在模型中显式表达，不能靠调用点自觉遵守。
- 后景计划必须穷举全部组合，逐一断言：生效组合、清屏透明度、根背景透明性、系统材质请求、纹理规格，以及回退原因。
- 展台必须同时呈现“用户选了什么”“实际生效了什么”“为什么回退”三件事，缺一件都会让对照失去意义。
- 自绘变体的配方按材质分档：云母变体在标准云母的配方上追加更深的色调层次，磨砂强度锚点两者一致。
